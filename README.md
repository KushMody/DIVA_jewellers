# DIVA_jewellers

Exquisite rings crafted with timeless elegance for life's most beautiful moments. Discover DIVA Jewellers fine diamond, engagement, and bespoke rings.

## Tech Stack
- **Framework**: React 19
- **Language**: TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Features
- **Cinematic Hero Carousel**: Staggered motion transitions, Ken-Burns scaling, and active timer progress indicators.
- **360° Ring Turntable & Anatomy Inspector**: Rotational ring view with anatomical hotspot callouts (prongs, under-gallery halo, ergonomic shank, BIS 750 hallmark).
- **Diamond 4Cs Gemological Laboratory**: Interactive Carat slider, Cut ray-tracing simulation, Color spectrum on dark/light backdrops, and 10x microscopic Clarity loupe.
- **Diamond Light & Nocturnal Lume Simulator**: Real-time lighting environments (Atelier 5500K, Candlelight Gala, Sunlight Prism, Nocturnal Luminescence).
- **Bespoke Ring Stacking Studio**: Curate 3-piece suites (solitaire centerpiece, eternity band, and tiara chevron crown) with live finger visualization.
- **Bespoke Serial Studio**: Horological chapter allocation (limited to 250 numbered iterations) with live laser hallmark & keepsake coin preview, plus custom text engraving.
- **Atelier Metamorphosis Slider**: Split comparison drag slider from raw earth crystal to finished 18K solitaire.
- **Smart Screen Sizing Calibrator**: 1:1 on-screen credit card calibration for precise ring sizing.
- **Vault Bag & WhatsApp Concierge Drawer**: Slide-over luxury bag with gift packaging options and instant WhatsApp consultation link generation.
- **Verified Patron Chronicles**: Real customer proposals and testimonials with interactive lightbox gallery.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
